# 法的・データ取得ルート（実装時の業務フロー）

## 弁護士
- 依頼受任・案件登録
- 必要性/相当性を検討
- 適切な法的手続を選択
- 弁護士会照会等への回答が得られた場合、回答原本をEvidenceへ保存
- 回答内容に位置情報が含まれる場合のみObservation化
- 照会を出したこと自体を「位置取得成功」と扱わない

個人情報保護委員会は、弁護士法23条の2に基づく弁護士会照会への回答は、
個人情報保護法上の「法令に基づく場合」に該当し、本人同意なしで提供できる場合があると説明している。
ただし回答可否は情報の性質や事案等に応じ個別判断となる。

## 探偵
- 探偵業者単独に弁護士法23条の2の照会権限はない
- 依頼目的・調査権限・契約を確認
- 適法な現場調査で得た観測をField Observationとして登録
- 弁護士手続が必要な部分は提携弁護士等の独立した適法手続へ分離
- システムが「探偵だからメーカー位置情報を取得できる」と表示しない

## メーカー/通信/データ事業者
- 公開APIがあるか
- 日本で利用可能か
- fleet/owner OAuthか
- 法的照会受付窓口があるか
- 位置/履歴の保存期間
- response format
- SLA
をProvider Registryで管理する。

## Google Geolocation等
観測端末が取得したcell/Wi-Fi情報から観測地点を推定する補助機能。
対象車両のVIN/IMEI/MACだけを遠隔入力して対象車両位置を返す機能ではない。
